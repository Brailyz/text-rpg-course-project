# Text RPG

Консольная текстовая ролевая игра на C++.

## Описание

Игрок создаёт персонажа, исследует игровой мир, взаимодействует с NPC,
выполняет задания, использует предметы и участвует в боях.

## Основные сущности

- Character
- Player
- Enemy
- NPC
- Item
- Weapon
- Armor
- Potion
- Quest
- Location
- Battle

## Технологии

- C++
- CMake
